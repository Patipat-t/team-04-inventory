# Persona: พี่นก สายยก

## ข้อมูลทั่วไป: อายุ 48 ปี / พนักงานจัดเก็บสินค้า / ประสบการณ์ 8 ปี / แท็บเล็ต Android 8 นิ้ว / ทักษะเทคโนโลยี: 2/5
## Quote ที่บ่งบอกตัวตน: "ขอปุ่มใหญ่ๆ ตัวหนังสือชัดๆ เวลาทำงานกลางแดดมองยาก ไม่อยากกดหลายหน้า"
## Goals:
1. บันทึกตัดสต็อกเสร็จใน 3 คลิกต่อรายการ
2. ไม่กดปุ่มผิดจนสต็อกในระบบคลาดเคลื่อน

## Frustrations:
1. ปุ่ม OK กับ ยกเลิก อยู่ชิดกันเกินไป กดผิดบ่อย
2. ช่องกรอกข้อมูลเป็นสีเทาอ่อน อ่านยากกลางแจ้ง
3. เวลาใส่ผิด ระบบขึ้นแค่คำว่า "Error" ไม่บอกวิธีแก้

## สิ่งที่ต้องการจากระบบใหม่:
1. ปุ่มกดขนาดใหญ่ พร้อมปุ่มยืนยันสีเข้มชัดเจน
2. ข้อความ Error สีแดงใต้ช่องที่กรอกผิด พร้อมอธิบายวิธีแก้
