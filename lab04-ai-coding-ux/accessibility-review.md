## จุดที่ AI ทำผิดพลาดและดำเนินการแก้ไขเอง:
1. **AI ใช้ Placeholder แทน Label:** ใน Text Wireframe รอบแรก AI ใส่ชื่อฟิลด์ไว้ข้างในช่องกรอก ทำให้เมื่อพิมพ์ข้อมูลแล้วมองไม่เห็นชื่อฟิลด์ -> **การแก้ไข:** แยกย้ายข้อความออกมาเป็น `<label>` ถาวรไว้ด้านบนทุกช่อง
2. **AI ลืมระบุ Error State และใช้สี Contrast ต่ำ:** AI ไม่ได้สร้าง layout ยามเกิด Validation Error และใช้สีเทาอ่อนสำหรับข้อความช่วยเหลือ -> **การแก้ไข:** ออกแบบ Error State เพิ่มเติม โดยใช้สีเตือน `#B45309` ร่วมกับไอคอนเตือนความผิดพลาด
