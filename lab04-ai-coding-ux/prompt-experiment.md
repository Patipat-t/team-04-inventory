# Prompt vs Context Experimentation - Lab 04

## รอบที่ 1: Prompt เปล่า (No Context)
* **Prompt ที่พิมพ์:** "เขียนฟังก์ชันตัดสต็อกสินค้าในคลังภาษา Python"
* **ผลลัพธ์ที่ได้:** AI เจนคลาส `InventoryManager` ขึ้นมาใหม่เอง ไม่ยอมใช้ Data Class หรือ Structure ที่มีอยู่แล้วในระบบ ต้องเขียนโค้ดแปลงข้อมูลใหม่ทั้งหมด

## รอบที่ 2: Prompt ที่มี Context (With Context)
* **Prompt ที่พิมพ์:** "เขียนฟังก์ชันตัดสต็อกสินค้าในคลัง"
* **Context ที่แนบไป:** ไฟล์ `src/models.py` เดิม, กำหนด Exception `ValueError` เมื่อสต็อกไม่พอ, และบังคับไม่ให้ใช้ Library นอก
* **ผลลัพธ์ที่ได้:** AI สร้างฟังก์ชันที่รับตัวแปรชนิด `Product` ได้ถูกต้อง ใช้งาน Type Hints ตรงตาม Interface เดิม และโยน `ValueError` ตามข้อกำหนดทันที

## สรุปผลการเปรียบเทียบ
* **สิ่งที่ต่างกัน:** ผลลัพธ์ในรอบที่ 2 สามารถนำไปเสียบเข้ากับโปรเจกต์เดิมได้ทันทีโดยไม่ต้องแก้ Interface
* **ปัจจัยที่ทำให้ต่าง:** Context (ไฟล์เดิม และข้อจำกัด) เป็นตัวบีบให้ AI สร้างโค้ดตามกรอบสถาปัตยกรรมเดิม ไม่เจนนอกเรื่อง
