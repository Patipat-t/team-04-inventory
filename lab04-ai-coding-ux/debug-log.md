# Debug Log - Lab 04

## Bug #1: Incorrect Quantity Logic
* **อาการที่พบ:** เมื่อใส่จำนวนสินค้าเป็นค่าลบ ระบบยอมให้ดำเนินการและเพิ่มจำนวนสินค้าแทนที่จะลดลง
* **สาเหตุ:** ฟังก์ชันตัดสต็อกขาดการตรวจสอบเงื่อนไข Boundary Check
* **วิธีแก้ไข:** เพิ่มเงื่อนไข `if qty <= 0: raise ValueError("Quantity must be greater than zero")` ก่อนเริ่มคำนวณ

## Bug #2: Missing Exception Handling
* **อาการที่พบ:** เมื่อค้นหารหัสสินค้าที่ไม่เคยมีในระบบ โปรแกรมแครชด้วย `KeyError` โดยไม่มี Error Message แจ้งผู้ใช้
* **สาเหตุ:** ไม่ได้ครอบบล็อก `try-except` สำหรับการเข้าถึง Key ใน Dictionary สินค้า
* **วิธีแก้ไข:** เพิ่มการจับ `KeyError` แล้วแปลงให้ส่งข้อความแจ้งเตือนที่เข้าใจง่าย
